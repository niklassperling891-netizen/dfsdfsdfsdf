# Drop Matching Items

Fabric-Client-Mod für Minecraft 1.21.11. Standard-Tastenkürzel: **G**.

1. Im Inventar, in einer Truhe, Shulkerbox oder einem Fass den Mauszeiger auf einen Itemstapel bewegen.
2. Das Tastenkürzel drücken.
3. Alle Stapel desselben Item-Typs in diesem geöffneten Inventar werden fallen gelassen (auch Varianten mit anderen Komponenten, etwa Verzauberungen).

Das Kürzel kann unter **Optionen → Steuerung → Tastenkürzel** geändert werden. Zum Bauen wird Java 21 benötigt; im Projektordner `gradlew.bat build` ausführen. Das Mod-JAR entsteht im Ordner `build/libs`.
